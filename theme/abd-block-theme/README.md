# DGL233 – Project 1: Custom Block Theme

This repository contains the custom WordPress block theme developed for DGL233 Project 1.

## Project Overview
The goal of this project is to plan, design, and build a custom WordPress block theme using hand-coded templates and a theme.json configuration.

## Development Notes
- This theme is developed locally using VS Code
- The theme is synced to a live AWS-hosted WordPress site via SFTP
- Version control is managed using GitHub
